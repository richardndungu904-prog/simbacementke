# simbacementltd — Simba Cement Ltd Website

A responsive, static multi-page marketing website for Simba Cement Kenya. The site presents products, project solutions, a preliminary material estimator, practical resources, and a Netlify-powered project enquiry form.

## Technology

- Semantic HTML5
- Custom responsive CSS
- Lightweight vanilla JavaScript
- Netlify Forms for enquiry handling
- Netlify configuration for static publishing and security headers

## Pages

- `index.html` — home and brand overview
- `catalogue.html` — full catalogue with product photos, descriptions and latest guide prices
- `products.html` — product range and indicative pricing
- `solutions.html` — recommendations by project type
- `estimator.html` — preliminary cement planning tool
- `resources.html` — site guidance and checklists
- `contact.html` — project enquiry form and contact details
- `thank-you.html` — successful form submission confirmation

## Search Engines

Every page has a description, canonical URL and social preview tags. The home, contact and catalogue pages include schema.org structured data (business details and product offers in KES). `sitemap.xml` and `robots.txt` are published from the root. URLs assume the site lives at `https://simbacementltd.netlify.app`.

## Local Use

No dependency installation or build step is required. Open `index.html` in a browser or serve the project root with any static file server. Form submission handling is active after deployment to Netlify.

## Deployment

The project publishes directly from the repository root using `netlify.toml`. Connect the repository to Netlify or upload the folder to deploy it.
